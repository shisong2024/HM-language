## 文档基线

初始基线为 2026-10-12 的主工作区：Cabal 版本 `0.1.0.0`，HEAD `b602833`（`implicit parameter`），包括当时用户对 `utils/prelude.txt` 的未提交改动。HEAD 和包版本不能单独代表这份工作区的全部内容。

本轮只核对源码和文档，不重新编译或验收主版本。主源码已经存在 R4/R5 的实现；历史 R5 副本的 351/0、18/18 是历史副本结果。主测试仍有旧接口残留，需要先迁移再建立当前测试基线。

## 持续维护约定

每次实质设计讨论更新 Design Notes：问题、初衷、目的、推荐方案、代价、状态和待决事项。用户明确同意后记录为“已确认”；仅有建议时记录为“提议”。功能采用并核对后才写入 Language Reference。

状态使用：`提议`、`已确认`、`实验中`、`隔离验证`、`主源码采用`、`主版本验收`、`推迟`、`被替代`。状态可以组合，例如“主源码采用；主版本尚未重新验收”。

历史记录不删除。归档表示不再作为当前计划入口，并不表示其中所有方案均已实现。
